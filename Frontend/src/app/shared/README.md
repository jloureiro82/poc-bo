# form-dropdown
Custom dropdown sample component to be used as template or base for new projects.
This dropdown uses tag `<details>` as base and accepts the use of `[formControl]` directive, demostration on `examples/form-sample/step2`

 - tag: `<mtc-form-dropdown>`
 - parameters: `[options]` receives a list of Option (containing id and name of option)
